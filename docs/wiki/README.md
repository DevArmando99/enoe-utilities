# Fuentes de la Wiki

Esta carpeta contiene la primera versión en español de la Wiki de `enoe-utilities`.

- `Home.md` es la portada.
- `_Sidebar.md` define la navegación lateral de GitHub Wiki.
- Las demás páginas usan nombres compatibles con las URL de la Wiki.

La fuente se conserva dentro del repositorio para que la documentación pueda revisarse mediante commits y pull requests. La publicación en la pestaña Wiki requiere que el repositorio especial `enoe-utilities.wiki` haya sido inicializado.
